## Обзор возможностей

-   Разрешает запуск выбранных приложений на заднем экране и
    поддерживает белый список активностей.
-   Управляет белым списком фоновых приложений и закреплением процессов,
    повышая стабильность работы приложений на заднем экране.
-   Позволяет настраивать белый список музыкальных элементов управления
    и обеспечивает совместимость с большим количеством мультимедийных
    приложений.
-   Расширяет отображение текстов песен: оригинал, перевод, романизация,
    разные провайдеры текстов и встроенные способы обработки.
-   Управляет шаблонами компонентов заднего экрана, маршрутизацией
    уведомлений, постоянно отображаемыми карточками, переменными
    шаблонов карточек и дополнительными параметрами отображения
    компонентов.
-   Устанавливает, обновляет и удаляет компоненты и обои через
    репозиторий компонентов заднего экрана.
-   Управляет обоями заднего экрана, автоматической сменой по
    расписанию, сортировкой перетаскиванием, импортом ресурсов,
    metadata, изображениями предварительного просмотра и настройками
    шаблонов.
-   Снимает ряд ограничений менеджера тем, включая ограничения
    длительности и частоты кадров видеообоев, отключения звука и
    количества шаблонов.
-   Убирает ограничения функций GMS в китайских прошивках.
-   Добавляет плитку быстрых настроек для переключения между основным и
    задним экраном, а также быстрые команды завершения выбранных
    приложений.

## Основные функции

### Настройки модуля

-   **Стиль темы**
    -   Поддерживаются два стиля: Miuix и Monet.
    -   Можно использовать системную тему, светлый или тёмный режим.
-   **Стиль панели навигации**
    -   Обычный, плавающий и плавающий стиль Liquid Glass.
-   **Стиль строки поиска**
    -   Стандартный стиль и стиль Miuix.
-   **API репозитория**
    -   Поддерживаются Alibaba Cloud, Cloudflare и пользовательский
        домен API.
    -   В пользовательском домене указывается только имя хоста, без
        `https://` и пути.
-   **Аппаратное ускорение WebView**
    -   Включено по умолчанию. Если предварительный просмотр Markdown
        приводит к сбою устройства, можно отключить ускорение и перейти
        на программный рендеринг.
-   **Избранные настройки**
    -   Удерживайте узел настройки, чтобы добавить его в избранное и
        быстрее находить часто используемые параметры.
-   **Скрытие значка приложения**
    -   Можно скрыть значок REAREye в лаунчере.
-   **Расширенный вывод отладочной информации**
    -   Помогает диагностировать работу модуля и проблемы совместимости.

### Улучшения системного фреймворка

-   **Белый список активностей для заднего экрана**
    -   Позволяет выбирать приложения, которые разрешено открывать на
        заднем экране.
    -   Список разрешённых приложений можно вести отдельно.
-   **Разрешить открытие всех Activity на заднем экране**
    -   Подходит для самостоятельного тестирования приложений без
        адаптации.
-   **Белый список фоновых приложений**
    -   Снижает вероятность того, что система завершит указанные
        приложения при использовании заднего экрана.
-   **Закрепление процессов приложений**
    -   Удерживает выбранные приложения в фоне с помощью более
        агрессивного механизма сохранения процесса.
-   **Запрет возврата на рабочий стол заднего экрана после блокировки**
    -   Сохраняет текущее состояние заднего экрана и уменьшает
        вероятность автоматического возврата после блокировки.
-   **Отключение защиты заднего экрана**
    -   При переходе основного экрана в полноэкранный режим задний экран
        больше не блокируется автоматически.

### Улучшения центра заднего экрана

#### Репозиторий компонентов заднего экрана

-   Просмотр, поиск и сортировка компонентов и обоев для заднего экрана.
-   Просмотр сведений о компонентах, README, описаний релизов,
    загружаемых ресурсов и информации о репозитории.
-   Установка компонентов и обоев.
-   Отображение хода установки, уведомления о новых версиях и проверка
    минимальной/максимальной поддерживаемой версии модуля.
-   Удаление установленных из репозитория компонентов с очисткой
    связанных шаблонов, карточек, маршрутов уведомлений или записей
    обоев.
-   Предупреждение о конфликтах при установке: можно удалить
    существующий компонент или принудительно перезаписать его.

#### Управление персонализацией заднего экрана

-   **Менеджер шаблонов компонентов**
    -   Управляет соответствием между компонентами и файлами шаблонов.
    -   Позволяет импортировать файлы шаблонов и сразу обновлять их
        сопоставление во время работы.
    -   Для компонентов из репозитория отображаются источник и статус
        блокировки, чтобы избежать случайного изменения.
-   **Менеджер маршрутизации уведомлений**
    -   Сопоставляет системные уведомления с компонентами заднего экрана
        по имени пакета и правилам уведомлений.
    -   Поддерживает точное совпадение и регулярные выражения.
    -   Синхронизирует состояние карточек заднего экрана при появлении и
        удалении уведомлений.
-   **Менеджер карточек**
    -   Управляет заголовком постоянно отображаемой карточки, целевым
        именем пакета, названием компонента, приоритетом и состоянием
        включения.
    -   Позволяет отключить постоянное отображение, сохранив
        конфигурацию карточки.
    -   Поддерживает настройку переменных шаблона для каждой карточки.
-   **Настройка шаблонов карточек**
    -   Поддерживаются текст, цвет, размер шрифта, выравнивание,
        изображения, даты, переключатели, выпадающие списки, Intent,
        фоновые ресурсы, анимация и строковые переменные.
    -   Поддерживаются предпросмотр в светлой/тёмной теме, просмотр
        изображений, импорт пользовательских изображений и открытие во
        внешнем редакторе.
-   **Менеджер дополнительных параметров компонентов**
    -   Позволяет вручную добавлять компоненты, которым нужны
        дополнительные параметры отображения.
    -   В текущей версии поддерживается отключение отображения времени
        уведомления для выбранного компонента.
-   **Разрешение отображения уведомлений с фокусом на заднем экране**
    -   Разрешает уведомлениям, уже содержащим корректные параметры
        фокуса/заднего экрана, отображаться на нём. При этом
        соответствующий компонент или шаблон всё равно должен
        существовать.

#### Менеджер обоев

-   Просмотр доступных в системе обоев заднего экрана, текущих обоев и
    их состояния.
-   Установка текущих обоев.
-   Добавление обоев в список автоматической смены.
-   Изменение порядка обоев перетаскиванием.
-   Настройка интервала переключения каждого изображения в
    миллисекундах.
-   Включение и отключение автоматической смены обоев заднего экрана.
-   Отображение состояний: текущие, в ротации, недоступные,
    редактируемые, сторонние и AON.
-   Импорт пакетов обоев MRC / ZIP.
-   Выбор или создание изображения предварительного просмотра.
-   Редактирование metadata обоев: название, описание, автор, дизайнер,
    категория, подтип ресурса, возможность редактирования, отметка
    стороннего ресурса и отметка AON.
-   Редактирование переменных обоев, для которых предусмотрена настройка
    шаблонов.
-   Удаление обоев, импортированных через REAREye или установленных из
    репозитория.

#### Улучшения музыкальных элементов управления

-   **Белый список музыкальных элементов управления**
    -   Позволяет выбирать приложения, чьи музыкальные элементы
        управления разрешено показывать на заднем экране.
    -   Лучше совместим с приложениями, использующими стандартные
        мультимедийные элементы управления.
-   **Принудительное обновление состояния музыкальных элементов
    управления**
    -   Исправляет задержки обновления элементов управления заднего
        экрана в некоторых приложениях после переключения песни или
        изменения состояния воспроизведения.

#### Улучшения отображения текстов песен

-   **Режим отображения текста песни**
    -   Оригинал, перевод и романизация.
-   **Выбор источника текстов песен**
    -   Поддерживается `Lyricon`.
    -   Поддерживается `SuperLyric`.
-   **Отображение имени исполнителя перед первой строкой**
    -   Работает со статическими текстами в формате LRC.
-   **Режим отображения построчного текста**
    -   Можно выбрать оригинальный текст или перевод.
-   **Удаление встроенных текстов из нативного API**
    -   Позволяет удалить исходные данные текста песни, предоставляемые
        метаданными Xiaomi.
-   **Пропуск обновлений метаданных, меняющих только название песни**
    -   Предотвращает вмешательство модуля текстов песен в ситуациях,
        когда, например, Bluetooth меняет только заголовок.
-   **Перехват встроенной логики обработки текстов песен**
    -   REAREye может самостоятельно обрабатывать прогресс и перенос
        строк текста песни либо отключить эту функцию и вернуться к
        системной логике.

#### Поведение видео и мультимедиа

-   Принудительное зацикливание видеообоев.
-   Регулировка громкости видеообоев с точностью от 0% до 100%.

### Улучшения менеджера тем

-   **Снятие ограничений видеообоев**
    -   Удаляет ограничение длительности видео.
    -   Удаляет стандартное ограничение частоты кадров, стараясь
        загружать видео с исходной частотой кадров.
-   **Снятие ограничения на количество шаблонов заднего экрана**
    -   Убирает ограничение на количество шаблонов, заданное
        производителем.
-   **Снятие ограничения на отключение звука видеообоев**
    -   Позволяет добавлять видеообои со звуком.
-   **Улучшенная синхронизация обоев заднего экрана**
    -   Совместно с менеджером обоев и процессом импорта поддерживает
        согласованность ресурсов в менеджере тем и рабочего состояния
        центра заднего экрана.

### Прочие функции

-   **Удаление ограничений GMS в китайских прошивках**
    -   Предназначено для снятия некоторых системных ограничений на
        функции Google.
    -   Например, проблем с доступностью хронологии и истории
        местоположений.

### Дополнительные функции

-   **Плитка быстрых настроек**
    -   Перемещает текущее приложение на задний экран.
    -   Возвращает на основной экран приложение, ранее перемещённое на
        задний экран.
-   **Состояние и быстрые действия на главной странице**
    -   Показывает состояние работы модуля, версию, канал сборки, статус
        обновления и статус Root.
    -   Предоставляет быстрые команды завершения процессов центра
        заднего экрана, менеджера тем и системного интерфейса.
-   **Страница «О приложении»**
    -   Содержит ссылки на проект, документацию, QQ-группу, страницу на
        Coolapk, список участников, которым выражена благодарность, и
        способы поддержки проекта.

## Область действия модуля

По умолчанию модуль действует на следующие целевые процессы:

-   `android`
-   `com.xiaomi.subscreencenter`
-   `com.android.thememanager`
-   `com.android.systemui`

## Требования

-   Android 16 / API 36 или новее.
-   Среда, совместимая с LSPosed / Xposed.
-   Минимальная версия Xposed: 93.
-   Устройство с задним экраном; текущий репозиторий ориентирован
    главным образом на Xiaomi 17 Pro / 17 Pro Max.
-   Для некоторых функций и быстрых действий требуется Root, например
    для быстрого завершения целевых приложений и переключения приложений
    между основным и задним экраном.
-   Для сетевых функций, таких как репозиторий компонентов заднего
    экрана, проверка обновлений и список участников, которым выражена
    благодарность, нужен доступ в интернет.

## Установка

1.  Скачайте и установите последнюю версию APK со страницы
    [Releases](https://github.com/killerprojecte/REAREye/releases).
2.  Включите `REAREye` в LSPosed или совместимом фреймворке.
3.  Убедитесь, что в область действия модуля входят: `android`,
    `com.xiaomi.subscreencenter`, `com.android.thememanager`,
    `com.android.systemui`.
4.  Перезагрузите устройство или как минимум перезапустите
    соответствующие целевые приложения, после чего откройте настройки
    модуля.
5.  Запустите приложение модуля и включите нужные функции.

## Инструкция по использованию

-   После изменения настроек белого списка заднего экрана, белого списка
    музыкальных элементов управления, шаблонов компонентов,
    маршрутизации уведомлений, карточек, автоматической смены обоев и
    других параметров рекомендуется перезапустить
    `com.xiaomi.subscreencenter`. Также можно воспользоваться быстрой
    командой завершения процесса на главной странице, а затем снова
    открыть центр заднего экрана.
-   Маршрутизация уведомлений зависит от взаимодействия
    `com.android.systemui` и `com.xiaomi.subscreencenter`. Если после
    изменения маршрутов настройки не применились сразу, перезапустите
    оба процесса.
-   Изменения системного фреймворка обычно требуют перезагрузки системы
    для стабильной работы.
-   После изменения параметров менеджера тем рекомендуется перезапустить
    `com.android.thememanager`, а при необходимости и всю систему.
-   Для некоторых быстрых действий и системных функций нужны Root-права.
    Убедитесь, что менеджер Root правильно выдал разрешения.
-   Компоненты, карточки и маршруты уведомлений, управляемые
    репозиторием, сохраняют информацию об источнике. Перед ручным
    управлением проверьте, нужно ли удалять или перезаписывать компонент
    из репозитория.
-   В модуле нет встроенного лаунчера для запуска приложений на заднем
    экране. Если нужно напрямую запускать там определённые приложения,
    можно использовать ADB или другой способ запуска.
-   После снятия ограничения на количество шаблонов всё равно
    рекомендуется самостоятельно проверять стабильность при очень
    большом их количестве.
-   Если предварительный просмотр Markdown в сведениях о репозитории
    вызывает сбой, отключите аппаратное ускорение WebView в настройках
    модуля.

## Для чего подходит модуль

-   Если нужно запускать или удерживать в рабочем состоянии больше
    приложений на заднем экране.
-   Если нужно использовать на заднем экране элементы управления
    сторонних музыкальных приложений.
-   Если нужно свободнее управлять источниками текстов песен,
    отображаемым содержимым и логикой обработки.
-   Если нужно устанавливать, обновлять и удалять компоненты или обои
    заднего экрана через репозиторий.
-   Если нужно самостоятельно управлять шаблонами компонентов,
    маршрутизацией уведомлений и постоянно отображаемыми карточками.
-   Если нужно настроить автоматическую смену обоев заднего экрана, их
    порядок, импорт, metadata и изображения предварительного просмотра.
-   Если нужно снять ограничения штатного менеджера тем на видеообои и
    количество шаблонов.
-   Если нужно обойти ограничения GMS в китайской прошивке без установки
    дополнительного модуля Magisk.

## Сборка из исходного кода

Проект использует Kotlin, Jetpack Compose, Android Gradle Plugin и
Gradle Wrapper.

-   JDK 17.
-   Android SDK / Build Tools 37.
-   SDK для компиляции: 37; минимальный SDK: 36; целевой SDK: 37.
-   Чтобы подписать Release-пакет, настройте в `local.properties`,
    свойствах Gradle или переменных окружения следующие параметры:
    -   `androidStoreFile`
    -   `KEYSTORE_PASSWORD`
    -   `KEY_ALIAS`
    -   `KEY_PASSWORD`

Часто используемые команды:

``` powershell
.\gradlew.bat assembleDebug
.\gradlew.bat assembleRelease
```

Собранные файлы находятся в `app/build/outputs/`. При Release-сборке
дополнительно экспортируется APK с изменённым именем.
